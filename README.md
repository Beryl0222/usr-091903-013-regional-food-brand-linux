# 地域餐饮品牌准入

服务用于维护地域餐饮品牌的标准、门店授权与动态退出，让技艺差异和质量底线同时得到保留。

## 领域能力（brand.py）

- **标准管理**：代表性菜品的标准版本、允许变体、核心食材产区与师傅传承关系在后端登记，不用统一配方抹掉门店技艺差异。
- **申请与评审**：申请方提交可验证的采购、制作与服务证据；评审中利益冲突者回避，回避后不足法定人数则暂缓决定，过半同意才授予准入范围。
- **处置与历史**：抽查不合格、供应中断或知识产权异议可触发限期整改、局部停权或退出；过去使用过标识的渠道和商品保留历史记录。
- **成效统计**：外卖、堂食与零售重复汇入的同一交易按交易编号去重，不多算成效。
- **数据授权**：门店依法授权经营数据的用途与期限，协会仅在授权范围内评估存续、农产品增值与就业带动。
- **公众摘要**：对外只提供当前有效门店、标准版本与退出原因的克制摘要。

## 运行与巡检

运行 `python3 service.py --check` 可核对服务配置；执行 `python3 service.py --port 8000` 后访问 `/health` 可确认服务身份，访问 `/public/summary` 可查看公众摘要。

## 测试

`npm test` 或 `python3 -m unittest -v service_contract brand_contract` 运行全部契约测试。
